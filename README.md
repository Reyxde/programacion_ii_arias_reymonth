## 🚀 Tecnologías Principales

### 🐍 Python
**Python** es un lenguaje de programación de alto nivel, interpretado y de propósito general. Destaca por su sintaxis clara y legible, lo que facilita el aprendizaje y acelera el desarrollo. Es la base tecnológica principal de esta materia y se utiliza ampliamente en desarrollo web, análisis de datos, inteligencia artificial y automatización.

### 🟣 Odoo
**Odoo** es una suite de aplicaciones empresariales de código abierto basada en Python. Funciona como un sistema ERP (*Enterprise Resource Planning*) modular y altamente personalizable que abarca áreas como gestión de ventas, CRM, inventarios, contabilidad y recursos humanos. Durante el curso nos enfocaremos en la creación y extensión de módulos personalizados dentro de esta plataforma.

### 🟢 Django
**Django** es un *framework* web de alto nivel escrito en Python que promueve el desarrollo rápido y un diseño limpio y pragmático. Sigue el patrón arquitectónico MVT (*Model-View-Template*) e incluye de manera nativa herramientas esenciales como un ORM (*Object-Relational Mapping*), un panel de administración automático, autenticación de usuarios y sistemas de seguridad integrados.
